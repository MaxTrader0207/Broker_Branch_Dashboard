研究流程

股票代碼 → 抓取券商分點 → 5/10/20/60 日 → 分點買賣超 → 主力集中度 → 主力成本 → 隔日沖辨識 → 吸籌/出貨辨識 → 主力轉向 → 外資/投信 → 融資融券 → MA/RSI/成交量 → 主力籌碼分數 0～100（規則版＋ML 版）→ 回測未來 5/10/20 日 → 勝率/平均報酬/最大回撤/資金規模滑價

V1.1 優化重點：動態流動性門檻、EMA 加權與族群建倉、FIFO/LIFO＋時間衰減成本、KDE 成本密集區、T+2/T+3 短沖特徵、K-Means 主力分群、扣當沖的留倉集中度、全市場家數差、隱性吸籌、散戶接盤、ATR／成本區防守線、PCA 降維、walk-forward ML Score、Z-Score 軟性選股、資金規模滑價回測。

V1.7 驗證層：S16 訊號台帳（每天存檔當日訊號、事後回填報酬，唯一真正的樣本外驗證）、S17 消融測試（逐一關掉各項優化，看哪些真的有用）。
V1.8：0050 含息基準、出場規則與大盤濾網對照（S15）、流動性／多空頭穩健性與分點加權（S17）、資料健康檢查（本頁下方）。

最重要的觀念：不要把「某分點買超」直接等於「主力買進」。分點資料 → 行為特徵 → 量化因子 → 回測 → 找出具有統計優勢的條件。
